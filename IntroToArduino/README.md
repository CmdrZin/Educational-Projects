# Introduction to Arduino Project

An educational project with Syllabus, Instructor's guide, and Student Handout for learning coding using the Arduino IDE.

==================

|        Name         | Description                                                |
|---------------------|------------------------------------------------------------|
|DataSheets | Data sheets for devices used in the examples.|  
|ITA\_Examples | Source code for coding projects used in the sections.|   
|KiCAD | KiCAD project source for the helper boards used in the sections.|  
|A000066-full-pinout.pdf | Arduino UNO 3 pin outs.|  
|IntroToArduino.pdf | Syllabus for the course.|  
|IntoToArduino\_Instructor.pdf | Instructor's guide for the course.|  
|IntoToArduino\_Student.pdf | Student handout for the course.|
